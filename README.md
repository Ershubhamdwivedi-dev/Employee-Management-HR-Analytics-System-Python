# 👨‍💼 Employee Management & HR Analytics System

A modern **Employee Management & HR Analytics System** built with **Python, Streamlit, SQLite, Pandas and Plotly**.
This application helps organizations manage employee records and get useful HR insights through an interactive dashboard.

---

## 🌟 Key Features

### 👨‍💼 Employee Management

* ➕ Add new employees
* ✏️ Update employee information
* 🗑️ Delete employee records
* 👁️ View complete employee details
* 🔍 Search employees easily

### 📊 HR Analytics Dashboard

* 👥 Total number of employees
* 🏢 Department-wise employee analysis
* 💰 Salary analysis
* 📈 Interactive charts and graphs
* 📊 Employee distribution analytics
* 📅 Employee-related statistics

### 🗄️ Database Management

* SQLite database integration
* Persistent employee records
* CRUD operations
* Structured employee data storage

### 🎨 Modern User Interface

* Clean Streamlit dashboard
* Interactive sidebar navigation
* Easy-to-use forms
* Responsive layout
* Professional dashboard design
* Interactive data tables

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository

```bash
git clone https://github.com/YOUR-USERNAME/Employee-Management-HR-Analytics.git
```

### 2️⃣ Open Project

```bash
cd Employee-Management-HR-Analytics
```

### 3️⃣ Install Required Libraries

```bash
pip install -r requirements.txt
```

### 4️⃣ Run Application

```bash
streamlit run app.py
```

---

## 📦 requirements.txt

```text
streamlit
pandas
plotly
```

SQLite is included with Python, so a separate SQLite installation is normally not required.
